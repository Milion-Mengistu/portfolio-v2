# Milion Mengistu Portfolio

A responsive personal portfolio website for Milion Mengistu, built to present experience, featured projects, technical skills, and contact information in a clear and polished format.

## Overview

This project is a static developer portfolio built with plain HTML, CSS, and JavaScript. It highlights:

- A hero section with professional summary and call-to-action links
- About and experience sections
- Featured project cards
- Frontend, backend, database, and tools skill groups
- Contact links for email, GitHub, LinkedIn, Telegram, and resume access

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Font Awesome

## Features

- Responsive layout for desktop and mobile screens
- Sticky navigation with active section highlighting
- Mobile navigation toggle
- Smooth scrolling between sections
- Dynamic footer year using JavaScript
- Clean visual design with custom typography and layered gradients

## Running Locally

Because this is a static site, no build step is required.

1. Clone or download the repository.
2. Open `index.html` in your browser.

If you want a local development server, you can use something simple like:

```bash
python3 -m http.server
```

Then open `http://localhost:8000`.

## Customization

To tailor the portfolio for your own use, update:

- `index.html` for content, links, and section copy
- `style.css` for colors, layout, spacing, and visual style
- `script.js` for navigation and interaction behavior
- `static/profile.png` for the profile image
